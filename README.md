  <h1>🎬 Movie Search App</h1>

  <p>A simple and responsive web application that allows users to search for movies and fetch detailed information using the OMDb API.</p>

  <h2>🚀 Features</h2>
  <ul>
    <li>Search for movies by title</li>
    <li>View movie details including poster, year, genre, and plot</li>
    <li>Responsive design for desktop and mobile</li>
    <li>Fast and clean user interface</li>
  </ul>

  <h2>🛠️ Technologies Used</h2>
  <ul>
    <li><strong>Frontend:</strong> React.js, Axios, React Router</li>
    <li><strong>Styling:</strong> CSS3, Material UI</li>
    <li><strong>API:</strong> OMDb API</li>
  </ul>

  <h2>📦 How to Run Locally</h2>
  <ol>
    <li>Clone the repository</li>
    <li>Run <code>npm install</code> to install dependencies</li>
    <li>Create a <code>.env</code> file with your OMDb API key:<br>
      <code>REACT_APP_OMDB_API_KEY=your_api_key_here</code>
    </li>
    <li>Run <code>npm start</code> to start the app</li>
    <li>Open <code>http://localhost:3000</code> in your browser</li>
  </ol>
