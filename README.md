  <h1>🎬 Movie Search App</h1>

  <p>A simple and responsive web application that allows users to search for movies and fetch detailed information using the OMDb API.</p>

  <h2>🚀 Features</h2>
  <ul>
    <li>Search for movies by title</li>
    <li>View movie details including poster, year, genre, and plot</li>
    <li>Responsive design for desktop and mobile</li>
    <li>Fast and clean user interface</li>
  </ul>

  <h2>🛠️ Technologies Used</h2>
  <ul>
    <li><strong>Frontend:</strong>HTML , CSS AND JAVASCRIPT </li>
    <li><strong>API:</strong> OMDb API</li>
  </ul>
